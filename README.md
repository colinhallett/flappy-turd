# Flappy Turd 💩👑

> *"Nobody flaps better than me. Believe me!"*

A hilarious HTML5 Canvas Flappy Bird parody featuring **Flappy Turd** — a poop emoji with a signature golden blond comb-over wig and red power tie.

![Flappy Turd Preview](https://img.shields.io/badge/Flap-Tremendous-gold?style=for-the-badge)

## Features

- 💩 **Signature Flappy Turd Character**: Coiled poop sprite with a flapping golden blond comb-over wig, red power tie, and animated expressions.
- 🏛️ **Gilded Obstacles**: Fly between golden columns and luxury pipes.
- 🎵 **Procedural Audio FX**: Synthesized sound effects with Web Audio API (fart flutters, toilet flushes, golden point chimes, fanfare chords).
- 💬 **Tremendous Quotes**: Dynamic commentary on milestones and hilarious quotes upon defeat ("TOTAL RIGGED HOAX! THE PIPES WERE CROOKED!").
- 🏆 **Medal System**: Bronze Plunger, Silver Toilet, Golden Bidet, and Diamond Throne.
- 📱 **Mobile & Desktop Friendly**: Touch controls, Spacebar / Arrow Up / Click support, responsive arcade layout.
- ⚡ **Zero-dependency Static Web App**: Ready for instant deployment on Vercel or GitHub Pages.

## Controls

- **Spacebar / Arrow Up / W / Tap / Click**: Flap
- **Mute Icon**: Toggle Sound FX
- **Share**: Brag about your high score

## Local Development

Run with any static server:

```bash
npx serve .
```
